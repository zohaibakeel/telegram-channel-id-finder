# Telegram Channel ID Finder

A simple Node.js tool to find the Chat ID of Telegram groups, channels, and users using the Telegram Bot API.

This project is useful for developers building Telegram bots.

## Features

- Find Group Chat ID
- Find Channel Chat ID
- Find User Chat ID
- Supports Bot API
- Beginner friendly

## Installation

```bash
git clone https://github.com/yourusername/telegram-channel-id-finder.git

cd telegram-channel-id-finder

npm install
```

## Usage

Create a `.env`

```
BOT_TOKEN=YOUR_BOT_TOKEN
```

Run

```bash
node index.js
```

Send a message in your Telegram group or channel.

The tool will print something like

```
Chat ID: -1002456789012
```

## Why use this?

Many Telegram APIs require the Chat ID instead of the username.

This tool helps you retrieve it instantly.
